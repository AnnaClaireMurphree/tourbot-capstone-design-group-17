# Tourbot Project

## Overview
This repository contains the software developed for our tourbot project.

## Current Status
**In development.** Currently implementing and testing the occupancy grid.

## Repository Structure
- `src/` — Main source code.
- `tests/` — Automated tests and written materials for test inputs.
- `docs/` — Design documentation and technical notes.
- `examples/` — Example inputs and demonstrations.

## Development Workflow
- Create a branch for each feature or bug fix.
- Test your changes before opening a pull request.
- Review changes before merging into the main branch.
